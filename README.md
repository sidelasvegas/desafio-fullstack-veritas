# Desafio Fullstack Veritas - Mini Kanban de Tarefas

Aplicação web de gerenciamento de tarefas desenvolvida como desafio técnico para a Veritas. O projeto consiste em um frontend em React consumindo uma API RESTful em Go.

## 🚀 Tecnologias Utilizadas

- **Frontend:** React (Vite), JavaScript ES6+, CSS3
- **Backend:** Go (net/http padrão, sem frameworks externos)
- **Documentação:** User Flow (PNG)
